# RO’Lyfe Funding & Execution Hub

A GitHub Pages-ready funding link page for RO’Lyfe.

## Purpose

This page connects funding calculators, loan type explainers, document access, booking, Jamal AI, contracts, credit/funding links, and PDF generation into one execution hub.

## Included

- Master Loan Calculator
- 15+ loan/funding use cases
- SBA, DSCR, working capital, MCA, franchise, credit repair, private money, bridge, real estate LOC, and more
- Funding package builder
- PDF funding preview generator
- Copy / email package buttons
- Lead save with local browser storage
- Jamal AI popup and embedded section
- Zoho Booking popup
- WorkDrive / Writer document preview
- Jotform Quick Docs upload
- RO’Lyfe links and credit/funding links
